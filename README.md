# boss-慧眼

## 📝 项目简介
这是一个帮助求职者提高简历投递效率的工具。本项目仅供学习和个人使用，请勿用于商业用途。

## 🎯 主要功能
- 过滤掉不在线的Hr提高沟通效率。

## 🚀 使用说明

### 方法一：本地安装（推荐）
1. 下载本项目代码并解压
2. 打开 Chrome 浏览器，在地址栏输入：`chrome://extensions/`
3. 打开右上角的「开发者模式」
4. 点击左上角的「加载已解压的扩展程序」
5. 选择解压后的文件夹
6. 安装完成后，在 Chrome 浏览器右上角可以看到插件图标

## ⚠️ 注意事项
- 插件安装后需要刷新 BOSS 直聘网页才能生效
- 请合理使用，避免频繁操作

## 💡 使用技巧
- 插件图标显示绿色表示正常运行
- 可以通过右键插件图标选择「选项」进行个性化设置
